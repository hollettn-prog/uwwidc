Links, videos & final checks

Use Canvas’s Links menu to connect items within your own course. Check that links do not lead to another instructor’s course. For videos, use a captioned recording and add a transcript or equivalent accessible text. The builder creates safe video links; use Canvas’s media tools to embed a player if needed.

Review in student view, run Canvas’s Accessibility Checker, and check links, dates, points, response settings and submission formats before publishing. Generated HTML does not set these options.
