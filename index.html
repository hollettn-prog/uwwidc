Add this page to your Canvas course

        
The builder prepares the page code; it does not save anything to Canvas. Copy the finished code, then add it to the course yourself.

        
    
          
  1. Finish the page here. Choose the page type, enter your information, and review the Preview and Canvas HTML tabs. Replace every sample value and instructor-update notice with confirmed course information.
    2. 
          
  2. Open your Canvas course. Go to Pages. Select + Page to create a page, or open the existing page and select Edit. Give the page a clear title.
    3. 
          
  3. Copy the code. Return to this builder, open Canvas HTML, and select Copy HTML. If copying is blocked, select the code and copy it manually.
    4. 
          
  4. Paste into Canvas. In Canvas’s Rich Content Editor, open the HTML Editor (often shown as </>). Paste the generated code into the editor. If you are replacing a page, replace its code only when you intend to replace its current content.
    5. 
          
  5. Save and review. Save the page, then inspect the rendered version. Check headings, links, images, video, transcript, dates, contact information, and any instructor-update notices. Test on a phone-sized screen too.
    6. 
          
  6. Publish when ready. Choose Save & Publish only after the page is ready for students. Editing a page that is already published may make the changes visible as soon as you save.
    7. 
          
  7. Add it to course navigation. If students should reach the page through a module, open Modules, add the page to the appropriate module, and confirm its position and availability.
    8.

Need a hand? Quick answers

    
This starter version includes guided help. It is not connected to a live AI service yet.

    
How do I add a video or link?
Use the link or media URL field for the page you are building. Confirm you have permission to share the media, use meaningful link text, and test it while signed in as a student. For embedded Canvas media, insert the video through Canvas after pasting the page, then preview it.

    
Why does my page show an instructor update notice?
The notice marks information that changes by instructor or term, such as dates, office hours, email, video, or schedule. Replace it with verified information before publishing; do not guess.

    
Can I paste this into Canvas as-is?
Use it as a starting point. Review the generated page, add course-approved links and content, and test the saved page. Canvas may adjust HTML when you save.

    
Can the helper answer a question not listed here?
Use the copy prompt below to ask your approved campus AI assistant for help. Include the page type and the exact issue, but do not include student records, private information, or credentials.
