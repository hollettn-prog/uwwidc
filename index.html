Add each page to your Canvas course

        
    
          
  1. Complete the five page forms. Use the page buttons on the left to move through Welcome, Meet Your Instructor, Syllabus and Calendar, Getting Help, and University Policies. Check the completion status for each page.
    2. 
          
  2. Create or open a Canvas page. In your course, open Pages. Select + Page to create one, or open the page you intend to revise and select Edit. Give it a clear title.
    3. 
          
  3. Copy the matching page code. Select that page in this builder, open Canvas HTML, and choose Copy this page's HTML. Repeat for each Start Here page.
    4. 
          
  4. Paste into Canvas. In the Rich Content Editor, open the HTML Editor (often shown as </>) and paste the copied code. Replace existing page code only when you intend to replace that page's current content.
    5. 
          
  5. Save and review each page. Check the rendered page, headings, links, media, dates, contact information, and any instructor update notices. Canvas may adjust pasted HTML.
    6. 
          
  6. Publish when ready. Use Save & Publish only when students should see the page. Saving changes to a page that is already published may make them visible right away.
    7. 
          
  7. Put the pages in the Start Here module. In Modules, add each saved page to the appropriate module and confirm the order and availability.
    8.

Need help?

    
This tool has quick guidance and a copyable question prompt. It is not connected to a live AI service.

    
What does “Required” mean?
Complete those fields before copying the page into Canvas. Optional fields can be left blank if they do not apply to your course.

    
How do I add a policy link?
In the University Policies form, enter one item per line as Policy name | https://official-url. Use only current official links and approved descriptions.

    
How can I get help with an issue?
Copy the prompt below and paste it into your approved campus AI assistant. Include the page name and describe what you need help with. Do not include private information, student records, or credentials.
