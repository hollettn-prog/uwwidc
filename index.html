Canvas Course Information Page Builder

Enter your course information, preview a consistent Canvas page, and copy the HTML into your course. Start with a sample or build one page at a time.

Reusable instructor tool · Draft pages only
BEFORE YOU START
This tool creates page content only. Check dates, links, contact details, and course-specific policies before publishing. Saving changes to an already published Canvas page may make them visible to students.

1. Choose a page and add your details

Term details receive an instructor-update notice in the output.

2. Review, copy, and use


      
  1. In Canvas, open Pages and select + Page (or open the page you intend to revise).
  2. Give the page a clear title. In the Rich Content Editor, switch to the HTML Editor.
  3. Copy the generated code from the Canvas HTML tab and paste it into the editor. Replace any remaining update notices with confirmed course information.
  4. Save the page. Review it in student view and check every link, video, heading, and image.
  5. Before publishing, confirm the course dates, contact details, official policy links, and page visibility settings.
SAFE TEMPLATE PRACTICE
This builder does not change Canvas, publish pages, change course settings, or touch grades or submissions. If replacing a live page, keep its existing content and links available until you have verified the new version.

    

  

  

    
Need a hand? Quick answers

    
This starter version includes guided help. It is not connected to a live AI service yet.

    
How do I add a video or link?
Use the link or media URL field for the page you are building. Confirm you have permission to share the media, use meaningful link text, and test it while signed in as a student. For embedded Canvas media, insert the video through Canvas after pasting the page, then preview it.

    
Why does my page show an instructor update notice?
The notice marks information that changes by instructor or term, such as dates, office hours, email, video, or schedule. Replace it with verified information before publishing; do not guess.

    
Can I paste this into Canvas as-is?
Use it as a starting point. Review the generated page, add course-approved links and content, and test the saved page. Canvas may adjust HTML when you save.

    
Can the helper answer a question not listed here?
Use the copy prompt below to ask your approved campus AI assistant for help. Include the page type and the exact issue, but do not include student records, private information, or credentials.

  

  
Put this tool on GitHub Pages
  1. Create or open a GitHub repository for the UWW Kinesiology page builder.
  2. Add this file at the repository root as index.html.
  3. In repository settings, enable GitHub Pages for the main branch and root folder.
  4. Open the Pages URL and test on a computer and phone. Share the tool with instructors after checking it with campus accessibility and Canvas guidance.
A live generative assistant can be added later through an approved secure service. Do not place an API key or private credential in this public page.
