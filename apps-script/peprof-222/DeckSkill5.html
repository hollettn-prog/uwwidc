Skill 5: Inclusive Adaptations & UDL

Reduce barriers while preserving meaningful participation

PEPROF 2221
SKILL 5

Access improves when options are designed before learners struggle

The learning goal stays clear; the pathway can change.

PEPROF 2222
START WITH THE BARRIER

The learner is not the problem to fix

What feature of the environment, task, equipment, or grouping limits participation?

Name the mismatch before proposing a solution.

PEPROF 2223
STEP FRAMEWORK

Four practical levers can increase access

SPACEDistance, size, boundaries
TASKRules, sequence, complexity
EQUIPMENTWeight, texture, sound, size
PEOPLEGrouping, support, roles
PEPROF 2224
PRESERVE THE GOAL

An adaptation should change access—not erase learning

Shared goal

Send an object toward a target with direction and control.

Responsive options

Use a larger/lighter object or a closer/larger target.

PEPROF 2225
BARRIER BUSTER

Create two different pathways to the same goal

Choose two STEP variables—not two versions of the same adjustment.

Explain which barrier each option reduces.

PEPROF 2226
CHOICE WITH PURPOSE

Useful choice supports agency without hiding expectations

Same goal
Clear options
Comparable meaning
Student dignity
No public labeling
PEPROF 2227
CHECK THE ADAPTATION

Would an observer still see the shared learning goal?

ACCESSCan the learner enter the task?
CHALLENGEIs there meaningful effort?
DIGNITYDoes the option avoid stigma?
EVIDENCECan progress still be observed?
PEPROF 2228
STEP STATIONS

Adapt space, task, equipment, and people

At each station, make one change and predict its effect.

Avoid assuming that easier automatically means more inclusive.

SKILL 5 CHECK
