# UWW Interactive Builders

This project retains the uwwidc repository and its existing GitHub Pages root. index.html remains the Start Here builder and module-builder.html remains the module builder. Their editable fields, preview, copy/download controls and local draft behavior remain intact. The approved purple gradient, lavender notices and centered UP NEXT output replace older presentation tokens.

All original Apps Script projects, clasp bindings and source logic remain in place. No deployment ID or Google permission was changed. The two course projects and the reusable template remain in their existing repositories. The Canvas Course Auditor stays in its separate development repository.

HEALTHED knowledge checks remain at their existing healthed445-interactives and healthed-445-course/interactives URLs. Do not remove either hosting location. This hub links those tools without moving or rebuilding them.

Instructor-only source, Canvas backups, quiz keys and private review evidence are excluded from public additions. Exact pre-update source archives and Git history bundles are retained privately by the instructor.
