# UWW Interactive Builders

Reusable UW–Whitewater Canvas page builders and preserved Apps Script source. Repository name: uwwidc. Existing GitHub Pages URLs remain unchanged.

- [Start Here builder](https://hollettn-prog.github.io/uwwidc/): five editable page types with preview and copy/download output.
- [Module builder](https://hollettn-prog.github.io/uwwidc/module-builder.html): existing course module authoring tool.
- [Course tools directory](https://hollettn-prog.github.io/uwwidc/course-tools.html): course review sites and reusable template.
- apps-script/: original projects and clasp bindings, with no server-side logic or deployment changes.

The approved design uses a deep-purple-to-violet header, white pages, neutral gray and lavender support, accessible focus indicators and centered UP NEXT navigation. See CONSOLIDATION.md for preservation and hosting boundaries. Exact originals are retained in Git history and in the instructor's private preservation archive.

The Canvas Course Auditor remains a separate utility. No keys, student records or private Canvas evidence should be added to this public repository.
